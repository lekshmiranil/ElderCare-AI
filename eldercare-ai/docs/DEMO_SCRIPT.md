# Demo script (about 6 minutes, works with no API key)

1. **Open the app.** Point out DEMO MODE and "AI: local mode" in the sidebar. "Everything works without a cloud API."
2. **Elderly dashboard.** Medicines with statuses, overdue warning, reminders, caregiver card. Click Taken on one medicine.
3. **Care Companion, by voice.** Click Speak: "What medicines do I take today". Open "How was this answered?": intent, urgency scores, route "deterministic handler". Explain: records are never answered by AI text.
4. **Safety.** Type "I feel dizzy" (urgent), "I passed out" (emergency), "What dose should I take" (refusal). Show the labels and explain the keyword rules plus the ML urgency model.
5. **Knowledge with sources.** "How can I prevent falls at home": passages and source title. "Tell me a joke": local reply saying AI chat is off.
6. **Reminder with confirmation.** "Remind me to drink water at 5 pm", then Yes. Show it on the dashboard. Try "remind me to take my tablets at 8 pm" (refused).
7. **Emergency button.** I need help, then the confirmation, then the result: it states plainly that nothing was actually sent.
8. **Fall detection.** Run "Hard fall" and "Stumble"; change the threshold; show the ML score and the history. State clearly that the data is simulated.
9. **Scan prescription.** Paste a prescription (or upload an image if OCR is installed), find medicines, set times, tick the confirmation, save.
10. **Caregiver dashboard.** Adherence chart, missed doses, wellness patterns with evidence, alerts, notifications, and Write summary.
11. **Gemini (optional, if a key is set).** Switch it on, ask an open question, point at the "AI-generated by Gemini" label and the usage counter. Ask it again to show the cached answer.
12. **Engineering.** `python -m pytest -q`, `python -m src.ai.evaluate`, and `docs/AI_EVALUATION.md` (including the first-run failure and what changed).

Questions to expect: why local ML plus rules instead of only an LLM (safety, cost, quota, offline); how quota is protected;
what is not claimed (real-world accuracy, medical advice); what you would do next (see README).
