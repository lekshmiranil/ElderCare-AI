# AI evaluation (local classifiers)

Generated by `python -m src.ai.evaluate`. Test sets are hand-written, small and English only, and are never used for training, so figures are indicative, not guarantees.

## Development notes
- First run (before any tuning): urgency accuracy 0.85, **emergency recall 0.70**. The model missed "i am going to faint", "i have taken too many pills" and "i passed out in the kitchen".
- Response: added training phrasings for those families, and added a deterministic keyword safety net that runs alongside the model (either one triggers the emergency message). The original urgency set is therefore a *development* set; the FRESH set was written afterwards and is the fairer estimate.
- A false alarm (showing the emergency message unnecessarily) is accepted over a missed emergency.
